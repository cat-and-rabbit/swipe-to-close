# Swipe to Close (for macOS)

リンクを新しいタブで開き、ページをクリックせずにMacトラックパッドの「戻る」スワイプで閉じる Chrome 拡張機能です。

タブ内で別のページへ移動した場合は通常どおり履歴を戻り、最初のページに戻ってからの次のスワイプで閉じます。ページ自身の履歴や保存データは書き換えません。

Chrome 106以降の通常のWebページが対象です。ブラウザ内部ページ、Chrome Web Store、iframe上の操作などは対象外です。戻るボタンやキーボードショートカットはChrome標準の動作になります。
